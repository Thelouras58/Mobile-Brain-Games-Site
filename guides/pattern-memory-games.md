## What makes a pattern game engaging?

Pattern games ask you to notice a sequence, shape, colour, or route, then reproduce it. The basic idea is easy to learn, but each new round can add a little more detail or ask for a faster response.

## Start with short rounds

Short rounds let you focus on the next pattern rather than a long set of instructions. Look carefully before responding, then try again when you want a new challenge.
