## A straightforward card-matching game

Simple Memory Game is an Android game about finding matching pairs. Turn over a card, remember where it is, and look for its pair as the board gradually becomes familiar.

## Built for easy, repeatable rounds

The game uses a clear card-matching format that is easy to understand for kids and enjoyable for families or anyone looking for a calm puzzle. Each round gives players another chance to improve their own time and score.
