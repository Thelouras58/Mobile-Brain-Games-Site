How to play

  1. Choose a difficulty and start a round.
  2. Select one card, then a second card.
  3. A matching pair stays visible. Different cards turn over again.
  4. Use the pictures and positions you have seen to find every pair.

The browser game stores game progress on this device. Clearing browser data may reset local progress.
