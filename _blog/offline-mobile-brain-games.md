## Offline games in the collection

- **Pattern Lock: Brain Games on Android:** recall a pattern, draw number combinations, or try Hack The Pattern.
- **Quick Tap on Android:** tap the numbers from 1 through 25 in order.
- **Word Sprint on Android:** connect letters in a changing grid to find words.
- **Memory Match on Android and iOS:** turn over picture cards to find matching pairs.

Offline play refers to the main game after installation. Downloads, updates, ads, store pages, web links, and connected services may still require internet access.

## What does “works offline” mean?

An offline claim normally describes the main game after it has already been installed. Downloading an app, installing an update, opening a store page, loading an advertisement, following a web link, or using a connected service can still require a connection.

A browser game is different. [Memory Match online]({{ '/memory-match/' | relative_url }}) lets you play without installing an app, but its files must first load in the browser. Do not assume that a browser game will open on a later offline visit unless that behavior is specifically supported and tested.

## How can I check before a trip?

Install or update the game while connected. Open it once, start the type of round you expect to play, and then test that same action with the device disconnected. Check optional features separately. A successful core round does not prove that every screen, purchase, advertisement, update, or external link is available offline.
